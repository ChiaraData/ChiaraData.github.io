API Estimateur de prix immobiliers L

Contexte et Objectifs

Ce projet est en cours de développement. Il s'inspire du chapitre fondateur du livre Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow d'Aurélien Géron, qui propose un exercice de prédiction de prix immobiliers sur le célèbre dataset californien. Plutôt que de reproduire l'exercice à l'identique, j'ai choisi de le reconstruire de bout en bout en l'adaptant au marché immobilier français : recherche des données, construction du dataset, ingénierie des features, modélisation, puis mise en production d'une API prédictive. Ce projet n'est pas disponible publiquement sur Github afin de prévenir toute réutilisation non autorisée. Pour plus d'informations, vous pouvez me contacter à l'adresse suivante : chiara.masi@etu.univ-amu.fr

Le défi principal a été de récupérer un dataset complet. J'ai donc constitué moi-même les données depuis plusieurs sources publiques, en créant notamment un fichier CSV dédié à la collecte des équipements de proximité (transports, commerces, écoles…), qui enrichit significativement la qualité des prédictions.

Réalisé par : Chiara Masi
Période : Avril 2026 — en cours
Statut : modèles de machine learning entraînés ; phase d’optimisation en cours (feature engineering, amélioration des performances et exploration de nouvelles variables)

Compétences et Outils Utilisés

Python (Pandas, NumPy) Scikit-learn FastAPI Visualisation (Matplotlib, Seaborn) Ingénierie de données & ETL

Sources de données : Demandes de Valeurs Foncières (DVF / data.gouv.fr) pour les transactions réelles, et un fichier CSV personnel créé manuellement pour la collecte des équipements locaux.

Approche Méthodologique et Modèles

Le projet suit un pipeline complet de machine learning, construit de zéro :

  • Collecte des données : Extraction et consolidation des sources DVF, OpenStreetMap et du fichier CSV d'équipements créé manuellement.
  • Feature Engineering itératif : Construction et amélioration continue des variables — surface, type de bien, densité d'équipements, encodage des variables catégorielles (type de bien, zone géographique).
  • Création d'un fichier CSV personnel : Récolte structurée des données d'équipements de proximité pour enrichir le dataset au-delà des sources publiques disponibles.
  • Modélisation et évaluation : Entraînement et comparaison de plusieurs modèles (Régression linéaire, Decision Tree, Random Forest, Gradient Boosting) via validation croisée (RMSE, MAE).
  • Mise en production : Une fois le modèle validé, déploiement sous forme d'API REST avec FastAPI pour exposer les prédictions.

Avancement et Résultats

Les étapes de collecte et de feature engineering ont été réalisées. Des modèles de machine learning ont été entraînés ; les premières évaluations montrent des performances encore perfectibles (erreur d’environ 0,53). Une phase d’optimisation est actuellement en cours, avec un travail sur l’enrichissement des données, l’ajout de nouvelles variables et l’amélioration des modèles.

Note d'expérience : Ce projet illustre ma capacité à construire un projet ML de A à Z en conditions réelles — sans dataset clé en main, en fabriquant moi-même les données manquantes et en itérant continuellement sur les features pour améliorer la performance du modèle.
